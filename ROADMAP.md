# ROADMAP

- Criar o projeto Next.js com TypeScript.
- Configurar Tailwind CSS.
- Configurar Prisma com SQLite.
- Criar os arquivos de orientação do projeto.

## Fase 2 - Núcleo do domínio

- Estruturar o schema do Prisma.
- Consolidar tipos e regras de domínio iniciais.
- Preparar a camada de acesso ao banco.

## Fase 3 - Clientes

- Listar clientes.
- Criar cliente.
- Editar cliente.

## Fase 4 - Ordens de serviço

- Listar OS.

- Consultar detalhes da OS.

## Fase 5 - Fluxos operacionais

- Itens por OS.
- Serviços por item.
